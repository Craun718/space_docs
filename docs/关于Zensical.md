# 关于 Zensical

本站点由 Zensical 通过 markdown 生成，你可在这里查看有关的信息。

## Zensical

Zensical 是 Material for MkDocs 作者打造的下一代静态站点生成器，基于 Rust 构建，构建速度比 MkDocs 快得多。

本站此前使用 MkDocs + Material 主题，由于上游 MkDocs 2.0 将移除插件系统并推翻主题体系，已迁移至 Zensical。
