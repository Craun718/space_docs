# 常用地图切片

## 地址参数说明

`{z}` 表示缩放级别，`{x}` 表示列号，`{y}` 表示行号。下面的地址是模板，使用时需由地图客户端替换占位符；`{key}` 需替换为自己申请的密钥。

普通 XYZ 图片切片通常使用 Web Mercator 投影，行号从北向南递增。投影相同不代表坐标基准相同，不能据此忽略高德 GCJ-02 等坐标偏移。

## 高德地图

### 标准地图（栅格切片）

包含道路、地名等要素，返回 PNG 图片，属于栅格切片，不是可单独修改要素样式的矢量瓦片。

```text
https://webrd01.is.autonavi.com/appmaptile?lang=zh_cn&size=1&scale=1&style=7&x={x}&y={y}&z={z}
```

高德采用 GCJ-02 坐标系，叠加 WGS84（如 GPS）数据时需要处理坐标偏移。

标准地图也可使用 `style=8`：

```text
https://webrd01.is.autonavi.com/appmaptile?lang=zh_cn&size=1&scale=1&style=8&x={x}&y={y}&z={z}
```

`style=7` 的 0 级、`style=8` 的 0–2 级可能返回空白。`webrd` 标准底图与 `webst` 卫星注记层需分别配置。

使用高德 JS API 2.0 时，可通过 `AMap.createDefaultLayer()` 创建标准底图。上述切片直连地址不属于该官方教程提供的接入方式。

参考：[高德官方图层](https://lbs.amap.com/api/javascript-api-v2/guide/layers/official-layers)、[坐标系说明](https://lbs.amap.com/api/javascript-api-v2/guide/abc/basetype)。

### 卫星图

国外地图仅提供低分辨率切片

```bash
https://webst01.is.autonavi.com/appmaptile?style=6&x={x}&y={y}&z={z}
```

### 卫星注记与混合地图

透明道路与地名注记，叠加卫星图组成混合地图。

```text
https://webst01.is.autonavi.com/appmaptile?style=8&x={x}&y={y}&z={z}
```

参考：[GeoLibre 区域底图配置](https://github.com/opengeos/GeoLibre/blob/main/packages/core/src/regional-basemaps.ts)。

## Google Maps

### 标准地图、卫星影像、混合与地形（栅格切片）

标准地图：

```text
https://mt1.google.com/vt/lyrs=m&hl=zh-CN&x={x}&y={y}&z={z}
```

卫星影像（不含道路与地名注记）：

```text
https://mt1.google.com/vt/lyrs=s&hl=zh-CN&x={x}&y={y}&z={z}
```

混合地图（卫星影像叠加道路与地名注记）：

```text
https://mt1.google.com/vt/lyrs=y&hl=zh-CN&x={x}&y={y}&z={z}
```

地形图：

```text
https://mt1.google.com/vt/lyrs=p&hl=zh-CN&x={x}&y={y}&z={z}
```

`hl=zh-CN` 指定中文注记语言。正式接入可使用下述 Map Tiles API。

### 官方 Map Tiles API

官方接入需配置 Google Cloud 项目、启用 Map Tiles API 和计费，并申请 API key。先向以下地址发送 `POST` 请求创建会话：

```text
https://tile.googleapis.com/v1/createSession?key={key}
```

设置请求头 `Content-Type: application/json`，卫星影像的请求体例如：

```json
{"mapType": "satellite", "language": "zh-CN", "region": "US"}
```

`mapType` 可设为 `roadmap` 或 `satellite`；地形使用 `terrain` 并添加 `"layerTypes": ["layerRoadmap"]`；混合地图使用 `satellite` 并添加 `"layerTypes": ["layerRoadmap"], "overlay": false`。`language` 和 `region` 按应用需要设置。

取得响应中的 `session` 后，使用对应会话请求瓦片：

```text
https://tile.googleapis.com/v1/2dtiles/{z}/{x}/{y}?session={session}&key={key}
```

`{session}` 需替换为有效会话令牌，到期后重新创建；实际尺寸、图片格式与到期时间以会话响应为准。展示地图时按官方政策保留 Google Maps 及数据提供方署名，并遵守缓存与使用限制。

参考：[Map Tiles API 概览](https://developers.google.com/maps/documentation/tile/overview)、[会话令牌及图层参数](https://developers.google.com/maps/documentation/tile/session_tokens)、[卫星瓦片](https://developers.google.com/maps/documentation/tile/satellite)、[使用与署名政策](https://developers.google.com/maps/documentation/tile/policies)。

## ArcGIS

### 矢量底图（PBF）

World Basemap v2 提供真正的矢量瓦片，由客户端根据样式绘制道路、水系、文字等要素。

服务地址：

```text
https://basemaps.arcgis.com/arcgis/rest/services/World_Basemap_v2/VectorTileServer
```

矢量瓦片地址，路径参数顺序为层级、行、列（`z/y/x`）：

```text
https://basemaps.arcgis.com/arcgis/rest/services/World_Basemap_v2/VectorTileServer/tile/{z}/{y}/{x}.pbf
```

配套样式地址：

```text
https://basemaps.arcgis.com/arcgis/rest/services/World_Basemap_v2/VectorTileServer/resources/styles/root.json
```

使用支持 ArcGIS 矢量瓦片的客户端加载服务及其样式，同时加载配套字体和图标资源；不能作为普通 PNG/JPG 图片切片加载。手动处理样式时，需要按样式文件所在地址解析其中的相对资源路径。

参考：[Esri 矢量底图与自定义样式](https://developers.arcgis.com/documentation/mapping-and-location-services/mapping/basemaps/custom-basemap-styles/)。

### 卫星图

```bash
https://server.arcgisonline.com/arcgis/rest/services/World_Imagery/MapServer/tile/{z}/{y}/{x}.png
```

## OpenStreetMap

### 标准地图（栅格切片）

全球道路底图，无需 API key。

```text
https://tile.openstreetmap.org/{z}/{x}/{y}.png
```

地图上需显示署名 `© OpenStreetMap contributors`，并链接到 [OpenStreetMap 版权页](https://www.openstreetmap.org/copyright)。公共服务器仅用于正常交互浏览，不允许批量下载、预取或离线下载；需遵守缓存规则，并发送有效的应用 User-Agent（浏览器可使用默认值）及网页 Referer。

参考：[官方切片使用政策](https://operations.osmfoundation.org/policies/tiles/)。

## 天地图

### 标准地图、影像与地形（WMTS 栅格切片）

需在[天地图控制台](https://console.tianditu.gov.cn/)申请密钥，将 `{key}` 替换为自己的 `tk`。下面使用 `_w` 墨卡托服务，底图与注记分开提供，通常需要叠加对应注记层。

通用 GetTile 地址：

```text
https://t0.tianditu.gov.cn/{layer}_w/wmts?SERVICE=WMTS&REQUEST=GetTile&VERSION=1.0.0&LAYER={layer}&STYLE=default&TILEMATRIXSET=w&FORMAT=tiles&TILEMATRIX={z}&TILEROW={y}&TILECOL={x}&tk={key}
```

将两处 `{layer}` 替换为同一个图层代码：

| 图层代码 | 内容 | 常用组合 |
| --- | --- | --- |
| `vec` | 标准地图底图 | `vec` + `cva` |
| `cva` | 标准地图中文注记 | 叠加在 `vec` 上 |
| `img` | 影像底图 | `img` + `cia` |
| `cia` | 影像中文注记 | 叠加在 `img` 上 |
| `ter` | 地形晕渲底图 | `ter` + `cta` |
| `cta` | 地形中文注记 | 叠加在 `ter` 上 |

例如，标准地图底图地址为：

```text
https://t0.tianditu.gov.cn/vec_w/wmts?SERVICE=WMTS&REQUEST=GetTile&VERSION=1.0.0&LAYER=vec&STYLE=default&TILEMATRIXSET=w&FORMAT=tiles&TILEMATRIX={z}&TILEROW={y}&TILECOL={x}&tk={key}
```

这里的“矢量底图”（`vec`）是地图内容分类，上述 WMTS 接口返回的是图片切片，不是 PBF 矢量瓦片。`_c` 经纬度服务使用另一套瓦片矩阵，不能只替换后缀就按相同 XYZ 配置加载。

调用时保留服务要求的版权标识，并按控制台配置应用权限与配额。

参考：[官方地图服务文档](https://lbs.tianditu.gov.cn/server/MapService.html)、[天地图图层类型说明](https://guangdong.tianditu.gov.cn/geomap-api/apidoc/jsNewApiDoc/GeoGlobe.TDTLayer.html)。

## CARTO

### 浅色、深色与彩色底图（栅格切片）

适合作为专题数据的背景。当前官方要求使用 API key，将 `{key}` 替换为自己申请的密钥；不带密钥的切片会显示要求提供密钥的水印。

Positron 浅色底图：

```text
https://a.basemaps.cartocdn.com/light_all/{z}/{x}/{y}.png?key={key}
```

Dark Matter 深色底图：

```text
https://a.basemaps.cartocdn.com/dark_all/{z}/{x}/{y}.png?key={key}
```

Voyager 彩色底图：

```text
https://a.basemaps.cartocdn.com/rastertiles/voyager/{z}/{x}/{y}.png?key={key}
```

支持 `0–20` 级；将 `.png` 改为 `@2x.png` 可获取双倍分辨率图片。`light_all`、`dark_all` 可分别替换为 `light_nolabels`、`dark_nolabels` 获取无注记底图。

地图上保留 OpenStreetMap 和 CARTO 署名。密钥申请及额度见 [CARTO Basemaps](https://carto.com/basemaps/apikey/)，地址格式与样式见[官方仓库](https://github.com/CartoDB/basemap-styles)。

## Mapzen Terrain Tiles

### Terrarium 高程瓦片（DEM，需客户端渲染）

全球高程数据，托管于 AWS 开放数据服务，无需 API key 或 AWS 账号。

```text
https://s3.amazonaws.com/elevation-tiles-prod/terrarium/{z}/{x}/{y}.png
```

PNG 的 RGB 通道编码的是海拔，原始颜色不是自然色影像，也不是已渲染的地形图。解码公式为 `高程（米）= R × 256 + G + B / 256 − 32768`，其中 R、G、B 为 `0–255` 的通道值。

数据融合了 SRTM、3DEP、EU-DEM 等高程产品。SRTM 通过雷达干涉测量获取高度；Terrarium 保存的是处理后的高程值，而非原始 SAR 回波强度或相位。

| 数据或图层 | 像素含义 | 展示方式 |
| --- | --- | --- |
| Terrarium PNG | RGB 编码的高程值，单位为米 | 解码后用于山体晕渲或三维地形 |
| SAR 强度影像 | 雷达回波强度，受坡度、地表粗糙度、介电性质等影响 | 对强度做拉伸等处理后显示 |
| OpenTopoMap 等地形底图 | 已绘制好的地图颜色，包含地形、道路、文字等内容 | 直接作为图片切片显示 |

山体晕渲由客户端根据高程和模拟光照生成，亮暗反映坡面朝向与坡度。需要道路、等高线和文字时，可叠加地图图层或使用 OpenTopoMap 等地形底图。

MapLibre GL JS 中应将 source 设为 `raster-dem`，指定 `encoding: "terrarium"`、`tileSize: 256`，再用 `hillshade` 图层或 terrain 功能渲染。署名应按实际覆盖区的数据来源要求保留，不能只标注托管方 AWS。

参考：[AWS Terrain Tiles 数据集](https://registry.opendata.aws/terrain-tiles/)、[Terrarium 编码说明](https://github.com/tilezen/joerd/blob/master/docs/formats.md#terrarium)、[高程数据来源](https://github.com/tilezen/joerd/blob/master/docs/data-sources.md)、[数据署名要求](https://github.com/tilezen/joerd/blob/master/docs/attribution.md)、[NASA SRTM 测高说明](https://www.jpl.nasa.gov/news/pictures-from-the-real-edge-nasa-posts-us-topography-data/)、[USGS SAR 强度与相位说明](https://www.usgs.gov/publications/interferometric-synthetic-aperture-radar-insar-its-past-present-and-future)。

## EOX Maps

### Sentinel-2 无云影像与地形

无需 API key。Sentinel-2 cloudless 是年度合成影像，适合全球遥感背景，不是实时影像，也不是城市级高分辨率航拍。

```text
https://tiles.maps.eox.at/wmts/1.0.0/s2cloudless-2025_3857/default/GoogleMapsCompatible/{z}/{y}/{x}.jpg
```

年份可替换为 `2018–2024`，路径顺序为 `z/y/x`。

| 内容 | 瓦片地址 |
| --- | --- |
| 浅色地形 | `https://tiles.maps.eox.at/wmts/1.0.0/terrain-light_3857/default/GoogleMapsCompatible/{z}/{y}/{x}.jpg` |
| 自然色地形 | `https://tiles.maps.eox.at/wmts/1.0.0/terrain_3857/default/g/{z}/{y}/{x}.jpg` |

注意自然色地形使用矩阵集 `g`，不能直接照搬其他图层的 `GoogleMapsCompatible` 路径。公共服务有流量限制且不保证可用性；无云影像免费使用受非商业许可约束，商业用途需按 EOX 许可办理。保留 EOX、Copernicus Sentinel 及各地形数据来源署名。

参考：[EOX Maps](https://maps.eox.at/)、[EOxCloudless 与许可](https://cloudless.eox.at/)。

## 腾讯地图

### 标准与深色地图（TMS 栅格切片）

采用 GCJ-02 坐标基准，叠加 WGS84 数据时需处理坐标偏移。

```text
https://rt0.map.gtimg.com/tile?z={z}&x={x}&y={y}&styleid=1&scene=0
```

将 `styleid=1` 改为 `styleid=4` 可切换深色。这里的 `{y}` 是从南向北递增的 **TMS 行号**：普通 XYZ 客户端需使用 `y_tms = 2^z - 1 - y_xyz` 转换；MapLibre 栅格 source 可设置 `scheme: "tms"`。

保留腾讯地图署名，接入要求见腾讯开放平台。

参考：[GeoLibre 区域底图配置](https://github.com/opengeos/GeoLibre/blob/main/packages/core/src/regional-basemaps.ts)、[腾讯位置服务](https://lbs.qq.com/)。

## 需密钥的其他底图服务

需申请自有密钥，并按服务商要求配置权限、配额与署名。

| 服务 | 地址模板 | 样式选项与说明 |
| --- | --- | --- |
| Protomaps（样式 JSON） | `https://api.protomaps.com/styles/v5/{style}/en.json?key={key}` | `light`、`dark`、`white`、`black`、`grayscale`、`contrast` |
| MapTiler（样式 JSON） | `https://api.maptiler.com/maps/{mapId}/style.json?key={key}` | 如 `streets-v4`、`outdoor-v4`、`satellite-v4`、`hybrid-v4`、`aquarelle-v4`、`ocean-v4` |
| Mapbox（样式 JSON） | `https://api.mapbox.com/styles/v1/mapbox/{styleId}?access_token={key}` | 如 `streets-v12`、`outdoors-v12`、`light-v11`、`dark-v11`、`satellite-v9`、`satellite-streets-v12`；需支持 Mapbox 资源协议与鉴权的客户端 |
| Amazon Location（样式 JSON） | `https://maps.geo.{region}.amazonaws.com/v2/styles/{style}/descriptor?key={key}` | `{region}` 为 AWS 区域；如 `Standard`，与密钥的区域和权限相匹配 |
| Stadia Maps（图片） | `https://tiles.stadiamaps.com/tiles/{style}/{z}/{x}/{y}.png?api_key={key}` | 如 `alidade_smooth`、`alidade_smooth_dark`、`outdoors`、`stamen_toner`、`stamen_terrain`；水彩使用 `stamen_watercolor` 并将扩展名改为 `.jpg` |

Stadia 也支持配置域名认证；Stamen 系列由 Stadia 提供，不使用旧的 Stamen 瓦片域名。样式 JSON 可能混合矢量与栅格资源，例如卫星样式中的影像仍是栅格。

参考：[GeoLibre 使用的底图库配置](https://github.com/opengeos/maplibre-gl-basemap-control/blob/main/src/lib/core/catalog.ts)、[Protomaps](https://protomaps.com/)、[MapTiler](https://docs.maptiler.com/)、[Mapbox](https://docs.mapbox.com/)、[Amazon Location](https://docs.aws.amazon.com/location/)、[Stadia 认证](https://docs.stadiamaps.com/authentication/)。
